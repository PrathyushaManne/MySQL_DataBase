# Database & MySQL

This repository contains my **database learning, practice work, and SQL exercises** focused on understanding how data is stored, organized, managed, and retrieved efficiently.

## What is a Database?

A **database** is an organized collection of data that allows information to be stored, managed, updated, and retrieved efficiently. Databases came into existence to overcome the limitations of traditional file-based systems and to handle large amounts of data in a structured and reliable way.
